# Sweet Admin 前端

## 初始化
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm install "$(cat ../.nvmrc)"
nvm use "$(cat ../.nvmrc)"
yarn
# or
npm install
```

### 启动程序
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use "$(cat ../.nvmrc)"
quasar dev
```


### 检查代码
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use "$(cat ../.nvmrc)"
yarn lint
# or
npm run lint
```


### 格式化文件
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use "$(cat ../.nvmrc)"
yarn format
# or
npm run format
```


### 打包发布
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use "$(cat ../.nvmrc)"
quasar build
```
