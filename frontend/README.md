# Sweet Admin 前端

## 初始化
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm install 22
nvm use 22
yarn
# or
npm install
```

### 启动程序
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use 22
quasar dev
```


### 检查代码
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use 22
yarn lint
# or
npm run lint
```


### 格式化文件
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use 22
yarn format
# or
npm run format
```


### 打包发布
```bash
cd /Users/nan/project/sweet-auth-base/frontend
nvm use 22
quasar build
```
