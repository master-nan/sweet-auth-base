# Report V2 信息架构

## 总体原则

Report V2 不再长期保留“报表中心”和“报表管理”两个重复概念。

V2 主入口收敛为：

```text
报表工作台
```

报表设计器不一定作为单独主菜单暴露，建议从工作台的新建和设计动作进入。

## 报表工作台结构

建议结构：

```text
报表工作台
  - 运行报表
  - 我的报表
  - 草稿箱
  - 设计管理
  - 发布版本
  - 执行日志
```

说明：

1. 运行报表：面向业务用户，展示可运行的 published 报表。
2. 我的报表：当前用户创建、收藏、最近使用的报表。
3. 草稿箱：未发布或正在编辑的报表。
4. 设计管理：管理员和设计人员维护报表定义。
5. 发布版本：查看报表发布历史，第一阶段只读。
6. 执行日志：查看运行、导出、设计预览日志。

## 用户角色视角

### 普通业务用户

普通业务用户主要看到：

1. 运行报表。
2. 我的报表。
3. 查询。
4. 导出。

普通用户不需要看到复杂设计动作，不需要理解草稿、版本快照、Sheet 绑定等概念。

### 管理员 / 设计人员

管理员和设计人员看到：

1. 新建报表。
2. 草稿箱。
3. 设计管理。
4. 发布。
5. 停用。
6. 版本。
7. 执行日志。
8. 运行。
9. 导出。

## 工作台页面分区

推荐工作台采用一个页面内的视图切换，而不是多个重复页面：

```text
顶部：搜索 | 状态筛选 | 分类 | 新建报表
左侧：我的报表 | 最近使用 | 分类 | 草稿箱
中间：报表列表 / 报表卡片
右侧或行操作：运行 | 导出 | 设计 | 发布 | 版本 | 停用
```

## 报表设计器入口

设计器入口来自工作台动作：

1. 新建报表。
2. 编辑草稿。
3. 设计已发布报表的新草稿。
4. 从旧 V1 报表进入高级 Sheet 模式。

设计器内部提供两种模式：

1. 快速表格报表。
2. 高级 Sheet 设计。

快速表格报表是默认推荐入口。

## 为什么不再长期保留报表中心 / 报表管理

V1 的“报表中心”和“报表管理”存在明显重复：

1. 两者都有列表。
2. 两者都有运行。
3. 两者都有导出。
4. 两者都有预览结果展示。
5. 两者对用户来说边界不够清晰。

V2 统一为报表工作台后：

1. 普通用户只看到运行相关能力。
2. 管理员在同一工作台看到设计和管理动作。
3. 页面逻辑可以复用，避免双页面重复实现。
4. 产品概念更接近低代码平台中的“工作台”。

## 开发期和正式期信息架构

开发期可以临时新增：

```text
报表工作台 Beta
```

仅给管理员或开发人员使用，不替换现有 V1 菜单。

转正期正式菜单建议：

```text
报表工作台
报表设计器（是否单独显示由权限和产品体验决定）
```

最终不要保留：

1. 报表 V2。
2. 新版报表。
3. 报表中心 + 报表管理两个重复入口。
