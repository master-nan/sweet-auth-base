# Report V2 UI 线框说明

## 1. 报表工作台页面

报表工作台是 V2 主入口。

```text
┌──────────────────────────────────────────────────────────────┐
│ 搜索报表名称 / 编码 / 分类     状态筛选   分类   新建报表     │
├───────────────┬──────────────────────────────────────────────┤
│ 我的报表       │ 报表列表                                     │
│ 最近使用       │ ┌──────────────────────────────────────────┐ │
│ 分类           │ │ 报表名称 | 状态 | 当前版本 | 更新时间 | 操作 │ │
│ 草稿箱         │ │ 运行 | 导出 | 设计 | 发布 | 版本 | 停用       │ │
│               │ └──────────────────────────────────────────┘ │
└───────────────┴──────────────────────────────────────────────┘
```

顶部：

1. 搜索。
2. 状态筛选。
3. 分类。
4. 新建报表。

左侧：

1. 我的报表。
2. 最近使用。
3. 分类。
4. 草稿箱。

中间：

1. 报表列表。
2. 报表卡片或表格。
3. 状态。
4. 当前版本。
5. 更新时间。

操作：

1. 运行。
2. 导出。
3. 设计。
4. 发布。
5. 版本。
6. 停用。

普通用户只看到运行和导出。管理员看到设计和管理动作。

## 2. 新建报表向导

```text
┌────────────────────────────────────────────┐
│ 新建报表                                   │
├────────────────────────────────────────────┤
│ 步骤 1 选择报表类型                        │
│   ○ 快速表格报表                           │
│   ○ 高级 Sheet 报表                        │
│                                            │
│ 步骤 2 基本信息                            │
│ 步骤 3 数据来源                            │
│ 步骤 4 字段和参数                          │
│ 步骤 5 预览并保存                          │
└────────────────────────────────────────────┘
```

步骤：

1. 选择报表类型：快速表格报表 / 高级 Sheet 报表。
2. 基本信息：名称、编码、分类、描述。
3. 数据来源：系统表、SQL 数据集、未来已保存数据集。
4. 字段和参数：字段选择、查询条件。
5. 预览并保存：生成草稿并设计时预览。

## 3. 快速表格设计器

快速表格报表是默认推荐入口。

```text
┌──────────────────────────────────────────────────────────────┐
│ 返回 | 报表名称 | 状态 | 保存草稿 | 保存并预览 | 发布 | 版本 │
├───────────────┬──────────────────────────────┬───────────────┤
│ 步骤导航       │ 当前步骤内容                  │ 当前步骤说明   │
│ 1 基本信息     │ 数据源选择                    │ 字段属性       │
│ 2 数据来源     │ 字段配置表格                  │ 发布检查摘要   │
│ 3 字段配置     │ 参数配置                      │               │
│ 4 查询条件     │ 生成布局                      │               │
│ 5 预览         │ 预览结果                      │               │
│ 6 发布         │                              │               │
└───────────────┴──────────────────────────────┴───────────────┘
```

快速表格报表流程：

1. 基本信息
   - 报表名称
   - 报表编码
   - 分类
   - 描述

2. 数据来源
   - 系统表
   - SQL 数据集，是否开放取决于管理员权限
   - 已保存数据集，后续阶段
   - 外部数据源，后续阶段

3. 字段配置
   - 勾选字段
   - 设置列名
   - 设置宽度
   - 设置对齐
   - 设置格式
   - 设置显示顺序

4. 查询条件
   - 文本
   - 数字
   - 日期
   - 日期范围
   - 下拉选择
   - 字典字段

5. 预览
   - 保存草稿
   - 设计时预览
   - 查看真实数据

6. 发布
   - 发布确认
   - 发布说明
   - 生成版本快照

快速表格模式不应该要求用户理解 cell、binding、formula、sheet row、sheet col。

## 4. 高级 Sheet 设计器

高级 Sheet 设计保留当前能力。

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部：返回 | 报表名称 | 状态 | 保存草稿 | 预览 | 发布 | 版本 │
├───────────────┬──────────────────────────────┬───────────────┤
│ 资源面板       │ ReportSheetCanvas            │ Inspector     │
│ 数据集         │                              │ 单元格属性    │
│ 字段           │                              │ 绑定属性      │
│ 参数           │                              │ 样式属性      │
│ Join           │                              │ 报表属性      │
└───────────────┴──────────────────────────────┴───────────────┘
```

高级 Sheet 支持：

1. 复杂表头。
2. 合并单元格。
3. 分组汇总。
4. 公式。
5. 自定义布局。
6. 类 Excel 布局。

高级 Sheet 模式复用：

1. `ReportSheetCanvas`
2. `ReportInspectorPanel`
3. `ReportResourcePanel`
4. `ReportSheetPreview`
5. `sheet/cell/binding` 模型

## 5. 报表运行页或运行弹窗

```text
┌──────────────────────────────────────────────────────────────┐
│ 报表名称                         当前版本：V3     导出 CSV   │
├──────────────────────────────────────────────────────────────┤
│ 参数区：动态参数表单                                      查询 │
├──────────────────────────────────────────────────────────────┤
│ ReportSheetPreview                                           │
├──────────────────────────────────────────────────────────────┤
│ 页码 | 每页条数 | 总数                                       │
└──────────────────────────────────────────────────────────────┘
```

结构：

1. 顶部：报表名称、当前版本、导出。
2. 参数区：动态参数表单。
3. 结果区：`ReportSheetPreview`。
4. 分页区：页码、每页条数、总数。

## 6. 版本弹窗

```text
┌────────────────────────────────────────────┐
│ 发布版本                                   │
├────────────────────────────────────────────┤
│ 版本号 | 状态 | 发布时间 | 发布人 | 当前版本 │
│ 发布说明                                   │
├────────────────────────────────────────────┤
│ 关闭                                       │
└────────────────────────────────────────────┘
```

展示：

1. 版本号。
2. 状态。
3. 发布时间。
4. 发布人。
5. 发布说明。
6. 当前版本标识。

第一阶段只读，不做回滚、diff、复制。

## 7. 发布弹窗

```text
┌────────────────────────────────────────────┐
│ 发布报表                                   │
├────────────────────────────────────────────┤
│ 配置校验摘要                               │
│ - 数据来源已配置                           │
│ - 字段已配置                               │
│ - 参数合法                                 │
│ - 权限配置提示                             │
│                                            │
│ 发布说明（可选）                           │
├────────────────────────────────────────────┤
│ 取消                              确认发布 │
└────────────────────────────────────────────┘
```

展示：

1. 发布确认。
2. 配置校验摘要。
3. 可选发布说明。
4. 发布后影响提示。
