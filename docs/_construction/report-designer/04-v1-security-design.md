# 报表设计器第一阶段安全设计

## 安全目标

第一阶段安全目标是为轻量报表设计器建立工程可落地的防线，而不是一次性解决所有 SQL 和数据权限问题。

目标：

1. 防止明显危险 SQL。
2. 防止多语句执行。
3. 防止 DDL / DML。
4. 防止长时间查询拖垮系统。
5. 防止无限制返回和导出。
6. 防止 SQL 报表默认对普通用户开放。
7. 保持普通表数据集继续复用现有数据权限。

## 权限分层

### 接口权限

继续复用现有认证和 Casbin。

所有接口必须位于后台认证组下，并接受 Casbin 路由权限控制。

### 菜单和按钮权限

继续复用现有菜单和按钮体系。

建议按钮权限至少区分：

- 查看
- 新增
- 编辑
- 删除
- 设计
- 发布
- 运行
- 导出

### 数据权限

普通 table 数据集继续复用现有数据权限体系。

规则：

1. 运行和导出必须应用数据权限。
2. 设计时预览也应应用数据权限。
3. join 报表至少对主表应用数据权限。
4. SQL 数据集第一阶段暂不承诺自动数据权限注入。

## SQL 安全守卫

第一阶段采用工程可落地的 SQL 安全守卫。

### 允许范围

只允许：

- `SELECT`
- `WITH`

### 禁止规则

必须禁止：

1. 多语句。
2. 分号。
3. DDL。
4. DML。
5. 权限变更语句。
6. 高危函数。
7. 明显长耗时语句。

建议禁止关键字或组合：

- `insert`
- `update`
- `delete`
- `drop`
- `alter`
- `create`
- `truncate`
- `merge`
- `replace`
- `grant`
- `revoke`
- `call`
- `execute`
- `exec`
- `copy`
- `vacuum`
- `reindex`
- `attach`
- `detach`
- `pragma`
- `explain analyze`
- `pg_sleep`
- `benchmark`
- `sleep`

### 参数规则

参数必须绑定，不允许字符串拼接参数值。

要求：

- 用户输入只进入绑定参数。
- 字段名和表名必须来自元数据或经过严格标识符校验。
- SQL 数据集追加条件时必须使用占位符。

## 查询限制

### 超时

所有报表查询必须设置查询超时。

建议第一阶段默认：

- 设计时预览：5 秒到 10 秒
- 运行查询：10 秒到 15 秒
- 导出查询：30 秒以内

具体值可通过配置项管理。

### 分页

运行接口必须分页。

建议：

- 默认 pageSize：20
- 最大 pageSize：200

超过最大值时，后端应强制截断。

### 导出行数

导出必须限制最大行数。

建议第一阶段默认：

- 最大导出行数：5000 或 10000

超过限制时应返回明确错误，或仅导出限制内数据并在结果中说明。

## SQL 报表默认权限

SQL 数据集风险高于 table 数据集。

第一阶段规则：

1. SQL 报表默认仅管理员可运行。
2. SQL 报表默认仅管理员可导出。
3. 普通用户运行 SQL 报表必须经过明确授权。
4. SQL 数据集暂不承诺自动数据权限注入。
5. SQL 报表发布前必须通过 SQL 安全守卫。

## 发布安全校验

发布时必须校验：

1. `query_config` 合法。
2. `layout_config` 合法。
3. dataset 至少存在一个有效主数据集。
4. table dataset 的 `source_code` 存在。
5. SQL dataset 通过 SQL 安全守卫。
6. 参数 schema 合法。
7. 字段绑定可解析。

发布失败时不得创建版本快照，不得更新 `published_version_id`。

## 运行安全校验

运行时必须校验：

1. 报表状态是 `published`。
2. 存在 `published_version_id`。
3. 发布版本存在且可用。
4. 用户有运行权限。
5. SQL 安全守卫通过。
6. 数据权限已应用。
7. pageSize 未超过最大限制。

## 导出安全校验

导出时必须校验：

1. 报表状态是 `published`。
2. 存在 `published_version_id`。
3. 发布版本存在且可用。
4. 用户有导出权限。
5. SQL 安全守卫通过。
6. 数据权限已应用。
7. 导出行数不超过最大限制。

## 执行日志

以下操作必须写执行日志：

- 设计时预览：`design_preview`
- 运行：`runtime_run`
- 导出：`runtime_export`

日志至少记录：

- 报表 ID
- 发布版本 ID
- 用户 ID
- 用户名称
- action
- 参数
- 成功状态
- 耗时
- 返回行数或导出行数
- 错误信息

## 第一阶段不承诺

第一阶段不承诺：

1. 完整 AST SQL 白名单。
2. SQL 数据集自动注入数据权限。
3. 外部数据库只读账号管理。
4. 跨数据源权限隔离。
5. 复杂 SQL 血缘分析。
