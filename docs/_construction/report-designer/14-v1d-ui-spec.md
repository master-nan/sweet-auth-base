# 报表模块 V1-D 前端 UI 设计说明

## 一、V1-D UI 总原则

1. 不重写设计器。
2. 不重做 sheet/cell/binding 模型。
3. 不新增复杂 UI。
4. 不做图表大屏。
5. 不做打印分页。
6. 不做填报。
7. 只接入设计预览、发布、运行、导出、版本查看。

## 二、页面结构

报表模块由 3 个页面 + 1 个弹窗组成。

### 1. 报表中心

- 面向业务用户运行 published 报表。
- 只展示 published 报表。
- 运行调用 `/run`。
- 导出调用 `/export`。
- 不出现设计、保存、发布、删除。

### 2. 报表管理

- 面向管理员管理报表。
- 支持设计、发布、运行、导出、版本、停用、删除。
- 发布调用 `/publish`。
- 运行调用 `/run`。
- 导出调用 `/export`。
- 版本打开 `ReportVersionDialog`。

### 3. 报表设计器

- 面向设计人员编辑草稿。
- 保留顶部工具栏。
- 保留左侧资源面板。
- 保留中间 sheet 画布。
- 保留右侧属性面板。
- 预览继续使用 `ReportSheetPreview`。
- 预览按钮语义改为“保存并预览”。
- 发布按钮语义改为“保存草稿并发布”。

### 4. 版本弹窗

- 展示版本号、状态、发布时间、发布人、发布说明、当前版本标识。
- 第一版只读。
- 不做回滚、diff、复制。

## 三、报表设计器布局

顶部工具栏：

```txt
返回 | 报表名称 | 状态 chip | 线上版本 | 参数 | 校验 | 保存草稿 | 保存并预览 | 发布 | 版本
```

左侧资源面板：

```txt
数据集、字段、参数、Join 配置
```

中间 sheet 画布：

```txt
单元格、字段绑定、分组、汇总、公式、样式
```

右侧属性面板：

```txt
单元格属性、绑定属性、样式属性、格式化属性
```

预览：

```txt
ReportSheetPreview
```

## 四、按钮语义

### 设计器

- 保存草稿：只调用 `create` / `update`。
- 保存并预览：先保存草稿，再调用 `/design-preview`。
- 发布：先保存草稿，再调用 `/publish`。
- 版本：打开 `ReportVersionDialog`。

### 管理页

- `draft`：设计、发布、删除。
- `published`：运行、导出、设计、发布、版本、停用、复制。
- `disabled`：设计、版本、删除；运行和导出禁用。

### 中心页

- 运行：调用 `/run`。
- 导出：调用 `/export`。

## 五、状态展示

统一展示：

- `draft`：草稿。
- `published`：已发布。
- `disabled`：已停用。

设计器顶部展示：

- 当前状态。
- 当前线上版本。

运行弹窗展示：

- 当前运行版本。

## 六、V1-D 不做内容

明确不做：

- 重写设计器。
- 图表大屏。
- 打印分页。
- 填报。
- 版本回滚。
- 版本 diff。
- 外部数据源。
- 数据集管理中心。
- 异步导出任务中心。
