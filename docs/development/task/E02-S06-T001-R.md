# E02-S06-T001-R Organization Center UI Refactor

## 1. 任务目标

按照 `Organization-Center-UI-Information-Architecture.md` 重构首批 Organization Center 只读页面：

1. 将“法人架构”调整为“法人主体”。
2. 将“管理架构”调整为“组织架构”。
3. 统一只读组织树浏览体验。
4. 单套 Structure 隐藏切换器，多套 Structure 显示后端数据驱动的“组织视图”。
5. 保持组织主数据镜像定位，不增加 HR、组织维护或 CRUD 能力。

## 2. 开始前工作区状态

任务开始前工作区已存在 Report、Frontend、design 和文档等历史未提交改动。

本 Task 未覆盖、回滚或提交这些历史改动。`frontend/src/router/routes.ts` 中既有 Report V2 改动继续保留，提交时只精确暂存本 Task 的 Organization 菜单标题片段。

## 3. 页面重构

### 3.1 法人主体

1. 页面和菜单统一使用“法人主体”。
2. 左侧使用专用只读树，右侧保留 `MasterDetailPage` 详情。
3. 点击节点加载详情；展开动作由树控件独立处理。
4. 删除重复详情操作列。
5. 上级法人通过当前树转换为“编码 - 名称”，不展示原始父级 ID。
6. 不展示源 ID、源版本或同步内部字段。

### 3.2 组织架构

1. 页面和菜单统一使用“组织架构”。
2. Structure 通过现有 `/admin/org/structure/query` 接口读取。
3. 单套有效 Structure 自动选择并隐藏切换器。
4. 多套有效 Structure 显示“组织视图”，选项名称直接使用 `org_structure.name`。
5. 多套 Structure 优先选择唯一的 `is_default`；不存在唯一默认项时等待用户显式选择。
6. 组织树节点用 `structure_node_id` 定位，详情继续使用 `org_unit_id`。
7. 详情隐藏节点 ID、父节点 ID、path、level 和源字段，只展示组织业务字段与当前组织视图。

## 4. 专用只读树

新增 `OrganizationReadOnlyTree`，复用 Quasar `q-tree`，没有建立第二套通用树体系。

组件规则：

1. 固定展开箭头、图标、名称、编码、类型和状态的布局，避免展开按钮换行。
2. 使用组织树连接线和层级缩进，不再以带操作列的表格表现组织树。
3. 没有操作列和详情按钮。
4. 展开状态更新不会触发选中事件。
5. 选中事件只由节点选择触发。
6. 搜索结果可以展开必要祖先路径。
