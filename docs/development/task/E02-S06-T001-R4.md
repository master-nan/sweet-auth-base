# E02-S06-T001-R4 Organization Center Page Refactor

## 1. Task 目标

将法人主体与组织架构页面从数据库字段浏览式主从页面，重构为组织主数据镜像浏览页面。

本 Task 不修改后端模型、API、权限、组织算法、菜单和 CRUD 边界。

## 2. 开始前工作区状态

任务开始前工作区已有 Report、Frontend、design 等历史未提交改动。本 Task 未覆盖、回滚、暂存或提交这些改动。

## 3. 删除的旧 UI

- 移除两个页面对 `MasterDetailPage` 的依赖及其 slot 式页面骨架。
- 移除旧的字段连续平铺详情结构。
- 不渲染操作列、详情按钮和眼睛按钮。
- 法人树不再展示主体类型，避免编码和类型争夺主视觉。
- 不展示 `id`、`source_id`、`structure_node_id`、`parent_node_id`、`path`、`level`。

## 4. 新页面结构

### 4.1 组织架构

- 独立页头：标题“组织架构”、副标题“组织主数据镜像浏览”、刷新操作。
- 仅当有效组织视图多于一个时显示“组织视图”选择器。
- 左侧为独立组织树面板，节点第一行突出组织名称，第二行显示编码和类型。
- 右侧为当前组织摘要和四个业务分组卡片：
  - 基础信息
  - 归属信息
  - 状态信息
  - 镜像信息
- 点击树节点加载详情，展开按钮只控制树展开。

### 4.2 法人主体

- 独立页头：标题“法人主体”、副标题“法人主数据镜像浏览”、刷新操作。
- 左侧法人树节点第一行突出法人名称，第二行仅显示法人编码。
- 右侧为当前法人摘要和四个业务分组卡片：
  - 基础信息
  - 主体信息
  - 状态信息
  - 镜像信息
- 点击树节点加载详情，无重复详情入口。

## 5. 截图验证

- 单组织视图隐藏选择器由自动化测试覆盖。
- DOM 检查确认四个详情分组均存在，技术字段未进入页面。
