# E02-S06-T004 同步批次与同步异常只读页面

## 任务目标

完成组织管理中的同步批次、同步异常页面，并补齐组织业务同步结果的只读查询、详情和受控错误查看接口。

## 实现范围

- 新增同步批次分页、快速查询、高级查询、详情及批次对象处理记录查看。
- 新增同步异常分页、快速查询、高级查询、普通详情和错误详情查看。
- 新增 `org_sync_batch`、`org_sync_record` 的只读 Repository、Service、Controller 和 Router 能力。
- 普通列表与详情仅返回诊断摘要；完整错误内容由独立 `view_error` 权限接口返回。
- `object_type + local_id` 支持从人员、岗位页面定位相关同步记录。

## 权限边界

- `query`：列表查询。
- `detail`：普通详情。
- `view_error`：错误摘要或完整错误信息。
- `refresh`：仅刷新当前列表。
- 未开放 `retry`、`ignore`，也未实现同步写入或真实源适配。
- `sys_menu_button` 是权限定义来源，Casbin policy 继续作为运行时投影。
