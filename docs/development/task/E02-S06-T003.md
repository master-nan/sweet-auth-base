# E02-S06-T003 人员、任职与岗位只读页面

## 任务目标

完成组织管理中的人员与任职、岗位两个只读管理页面，复用既有组织查询服务、功能权限和平台列表组件。

## 实现范围

- 新增人员与任职页面：分页、快速查询、高级查询、状态筛选、账号绑定状态、详情及当前/历史/未来/时间轴任职查看。
- 接入已有员工账号绑定、解绑能力；绑定关系仍只表示当前 Sweet Platform 实例账号。
- 新增岗位页面：分页、快速查询、高级查询、状态筛选和只读详情。
- 人员与岗位均可按已有 `view_sync` 动作跳转到同步异常，并携带对象类型与本地对象 ID。
- 前端值继续使用 `employee_id`、`position_id`，不以 `user_id`、名称或源系统 ID 替代业务标识。

## 权限与隐私

- 页面操作由 `usePageButtons` 读取 `query`、`detail`、`bind_user`、`unbind_user`、`view_sync`、`refresh`。
- 联系方式仅展示后端脱敏字段。
- 账号摘要不包含密码、令牌、角色或权限信息。
- 页面不提供人员、岗位、任职的新增、修改、删除入口。
