## 3. 修改原因

当前迁移和 Seed 已具备较多平台基础能力，但执行入口仍以直接串行调用为主。进入 P2A/P2B 正式开发后，统一集成中心和组织主数据镜像中心都会新增模型、字典、元数据、菜单和按钮。若没有明确注册点，后续容易继续散落追加，增加重复、漏注册和顺序错误风险。

本次通过注册清单规范化执行流程，确保后续平台 Seed 统一遵循：

1. 先迁移 Schema。
2. 再补结构修复和幂等 backfill。
3. Seed 时先写基础配置和字典。
4. 再写菜单、按钮和 Casbin。
5. 再扫描生成 `sys_table` / `sys_table_field`。
6. 再写 `sys_table_relation`。
7. 最后刷新可重建缓存。
