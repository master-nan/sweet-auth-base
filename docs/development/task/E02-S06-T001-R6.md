# E02-S06-T001-R6 组织架构页面样式与深色模式修正

## 任务目标

修正组织架构统一入口验收中发现的四项页面问题：

1. 刷新操作被按钮元数据文字撑开。
2. 组织树自定义连接线与 Quasar 原生连接线重叠。
3. 组织节点图标颜色和底座过重。
4. 页面自定义区域未适配平台深色主题。

## 修改内容

- 刷新操作改为固定尺寸的纯图标按钮，名称仅通过 Tooltip 和
  `aria-label` 表达。
- 删除组织树额外绘制的左侧边线，保留并统一使用 Quasar 原生连接线。
- 管理组织节点使用 `corporate_fare`，法人节点继续使用
  `account_balance`；图标改为中性色且取消彩色底座。
- 页面头部、卡片、树、详情字段、空状态、错误状态和表单控件接入平台
  `body--dark` 主题变量。

## 边界

本次未修改后端模型、组织 API、组织算法、权限、菜单和数据库；未新增
组织 CRUD，也未修改 Report、数据权限或低代码运行逻辑。

## 测试

- 组件测试覆盖刷新按钮纯图标约束、管理组织新图标和既有树交互。
- `yarn test`：9 个测试文件、57 个用例通过。
- `yarn lint`：通过。
- `yarn typecheck`：通过。
- `yarn build`：通过；仅保留项目既有的大分包提示。
- 浏览器亮色和深色验证通过：刷新按钮实测为 `36 × 36`，组织树子级容器
  不再绘制额外边框，节点图标为透明底中性色，页面无横向溢出。
