# E02-S06-T001-R3 Organization Center UX Refinement

## 1. Task 目标

优化组织架构与法人主体只读页面的信息层级，使页面表达从字段浏览转向组织主数据业务浏览。

本 Task 不修改后端模型、API、权限、组织算法和 CRUD 边界。

## 2. 开始前工作区状态

任务开始前工作区已有 Report、Frontend、design 等历史未提交改动。本 Task 不覆盖、不回滚、不暂存这些改动。

## 3. 页面体验调整

### 3.1 组织树

- 节点名称作为主视觉。
- 编码和类型作为同一行辅助信息。
- 状态降低视觉权重。
- 使用组织图标、层级引导线和选中标识强化树结构。
- 页面副标题明确标识“组织主数据镜像”。
- 节点点击仍只负责查看详情，展开按钮仍只负责展开。

### 3.2 组织架构详情

详情按业务语义分为：

1. 基础信息：组织名称、组织编码、组织类型。
2. 归属信息：组织视图、主要法人。
3. 状态信息：状态、有效期。
4. 镜像信息：更新时间、平台备注。

### 3.3 法人档案详情

法人档案使用相同的信息层级：

1. 基础信息：名称、简称、编码、主体类型。
2. 归属信息：上级法人、统一社会信用代码、核算编码。
3. 状态信息：状态、有效期。
4. 镜像信息：更新时间、平台备注。

## 4. 技术字段边界

页面继续隐藏：

- `structure_node_id`
- `parent_node_id`
- `path`
- `level`
- `source_id`

页面不新增编辑、删除、调岗、离职或组织调整入口。

## 5. 修改范围

- 组织只读树共享组件。
- 组织只读详情共享组件及分组类型。
- 组织架构与法人档案页面字段分组。
- 页面与共享组件回归测试。
