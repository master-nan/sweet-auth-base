# E02-S06-T001-R5 组织架构统一入口调整

## 任务目标

按实际产品认知统一 Organization Center 入口：

- 一级菜单名称为“组织管理”。
- 一级菜单下只保留“组织架构”作为当前已实现入口。
- 同一页面通过“架构类型”切换管理架构与法人架构。
- 管理架构存在多套 `org_structure` 时才显示“管理视图”选择器。
- 详情使用连续信息区，不再按多个卡片分组。

## 领域边界

- 法人架构继续使用 `org_legal_entity.parent_id`。
- 管理架构继续使用 `org_structure + org_structure_node + org_unit`。
- 页面统一不改变领域模型，也不混用 `legal_entity_id`、`org_unit_id`
  和 `structure_node_id`。
- 未修改组织查询 API、组织树算法和数据库模型。

## 实施内容

1. 将原“组织主数据”菜单标题调整为“组织管理”。
2. 移除独立“法人主体”功能菜单，将法人查询、树、详情和选项权限归属到
   “组织架构”菜单。
3. 旧法人菜单的角色菜单授权和六项按钮/API 授权幂等迁移到统一入口，
   旧菜单停用并隐藏。
4. 保留旧前端地址为隐藏重定向，已有书签进入统一页面的法人架构模式。
5. 统一页面新增“架构类型”下拉；管理架构多视图时显示“管理视图”下拉。
6. 右侧详情改为连续字段布局，隐藏节点 ID、路径、层级和源内部字段。
7. 移除页面固定最小宽度，窄桌面窗口不再产生页面横向滚动。
